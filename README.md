# Sales Performance Dashboard

## 📊 Project Overview

This project was completed as part of my **Data Analyst Internship at BeSkilled**. The objective was to analyze sales data and develop an interactive dashboard to monitor sales performance and identify key business insights.

## 🎯 Objectives

- Analyze overall sales performance
- Track key performance indicators (KPIs)
- Identify sales trends and patterns
- Compare sales performance across categories
- Create interactive visualizations for data-driven decision-making

## 🛠️ Tools & Technologies

- **Power BI**
- **DAX**
- **Microsoft Excel**

## 🔍 Key Tasks

- Prepared and transformed sales data for analysis
- Created calculated measures using **DAX**
- Developed interactive **KPI cards and visualizations**
- Analyzed sales trends and performance
- Designed an interactive Power BI dashboard

## 📈 Dashboard

The dashboard provides an interactive view of sales performance, allowing users to explore key metrics and identify trends through dynamic visualizations.

## 💡 Key Skills Demonstrated

**Data Analysis | Data Visualization | Power BI | DAX | KPI Analysis | Dashboard Development | Data Transformation**
